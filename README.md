# مدیری‌نیوز (mehran-news)

یک سایت خبری مینیمال و فارسی درباره‌ی **مهران مدیری** که اخبار را از فیدهای بینگ‌نیوز و گوگل‌نیوز جمع می‌کند، در **Cloudflare D1** ذخیره می‌کند و با **Cloudflare Workers** سرو می‌کند. سایت شامل حساب کاربری، پنل ادمین، نظر، لایک، فیلتر کلمات نامناسب و ربات تلگرام است.

**نسخه‌ی زنده:** <https://mehran-news.farshidgholizadeh.workers.dev>

## امکانات

### خبرها
- واکشی خودکار از بینگ‌نیوز (فارسی و انگلیسی) و گوگل‌نیوز
- فیلتر بر اساس نام «مهران مدیری» و حذف موارد نامرتبط
- حذف تکراری‌ها بر اساس لینک اصلی خبر
- نمایش گروه‌بندی‌شده بر اساس روز شمسی (امروز، دیروز، ۱۲ آبان و…) در حالت «جدیدترین»
- صفحه‌بندی ۱۰ خبر در هر صفحه و مرتب‌سازی بر اساس جدیدترین، محبوب‌ترین (لایک) و پرنظرترین
- به‌روزرسانی خودکار هر ۶ ساعت با Cron Trigger و دکمه‌ی به‌روزرسانی دستی (فقط ادمین)
- تصویر بندانگشتی، منبع، زمان نسبی و خلاصه‌ی هر خبر
- در موبایل تصویر هر خبر تمام‌عرض نمایش داده می‌شود و عنوان و متن زیر آن می‌آیند
- فقط خبرهای ۴۵ روز اخیر (قابل تغییر) وارد صفحه می‌شوند

### کاربران و دسترسی‌ها
- دو نوع حساب: **ادمین** و **کاربر معمولی**
- ثبت‌نام با نام کاربری و رمز عبور؛ حساب جدید تا تأیید ادمین در وضعیت «در انتظار» می‌ماند
- صفحه‌ی ورود مشترک برای هر دو نقش؛ دسترسی‌ها بر اساس نقش تعیین می‌شود
- پنل کاربری شامل تنظیم اعلان تلگرام و ارسال پیام مستقیم به مدیریت است (بدون نیاز به شماره موبایل)؛ پیام کاربر هم قبل از ارسال با فیلتر کلمات نامناسب بررسی می‌شود
- نشست امن با کوکی `HttpOnly` و توکن هش‌شده در دیتابیس
- رمزها با PBKDF2-SHA256 و نمک تصادفی ذخیره می‌شوند
- محدودیت تلاش ناموفق ورود (۸ تلاش در ۱۰ دقیقه برای هر IP و نام کاربری)

### پنل ادمین
- نمای کلی با تایل‌های کلیک‌پذیر برای رفتن مستقیم به خبر، آرشیو، نظرها، کاربران و پیام‌ها
- حذف، آرشیو و بازگردانی خبر
- تأیید، بلاک و رفع بلاک کاربران
- ساخت ادمین جدید یا ارتقای کاربر به ادمین
- اجازه یا قطع دریافت اعلان تلگرام برای هر کاربر
- پاسخ به هر نظر (حتی نظر در انتظار)؛ با ثبت پاسخ، نظر تأیید و زیر همان نظر در سایت منتشر می‌شود
- صندوق پیام‌های کاربران با وضعیت خوانده‌شده/خوانده‌نشده

### نظر و لایک
- نظر دادن روی هر خبر؛ نظر کاربران عادی پس از تأیید ادمین نمایش داده می‌شود
- نظر ادمین بدون نیاز به تأیید منتشر می‌شود
- پاسخ ادمین زیر نظر کاربر نمایش داده می‌شود
- فیلتر پیش‌فرض کلمات نامناسب با نرمال‌سازی فارسی (حروف عربی/فارسی، نیم‌فاصله، اعراب، تکرار حروف و فاصله‌گذاری دور زدن فیلتر را سخت می‌کند)
- لایک خبر برای کاربران واردشده؛ لایک و برداشتن لایک بدون باز شدن صفحه و بدون بارگذاری مجدد انجام می‌شود

### ربات تلگرام (اختیاری)
- اعلان فوری خبرهای تازه برای کاربرانی که دریافت اعلان را فعال کرده‌اند
- اتصال حساب سایت به تلگرام فقط با لینک اختصاصی (بدون شماره موبایل)
- دکمه‌های ثابت در پایین صفحه؛ هر بخش (پروفایل، اعلان‌ها، اخبار، مدیریت) پیام تازه‌ی خودش را می‌فرستد و پیام قبلی بازنویسی نمی‌شود
- سوییچ اعلان با دکمه‌ی درون‌خطی که وضعیت «روشن/خاموش» را روی خودش نشان می‌دهد و با هر لمس فقط همان دکمه عوض می‌شود (بدون نوشتن پیام تازه)
- «آخرین اخبار» پنج پیام مستقل می‌فرستد؛ هر پیام یک خبر با دکمه‌ی «باز کردن خبر» و بدون نمایش لینک خام
- دکمه‌ی «بک» و دکمه‌های «بستن منو»/«بازگشت» حذف شده‌اند
- هشدار فوری در تلگرام برای ادمین‌ها هنگام ثبت نظر تازه یا ثبت‌نام کاربر جدید، همراه با دکمه‌ی رفتن به پنل
- اعلان مستقیم پاسخ ادمین به کاربر در تلگرام (در صورت اتصال حساب و اجازه‌ی ادمین؛ مستقل از سوییچ اعلان خبری)
- انجام کارهای مدیریتی از داخل ربات: تأیید نظر، تأیید/بلاک کاربر، آرشیو/حذف خبر

## معماری

```text
مرورگر / موبایل / تلگرام
      │
      ▼
Cloudflare Worker  ──── fetch ────►  بینگ‌نیوز / گوگل‌نیوز (RSS)
      │                    │
      │                    └────────►  Telegram Bot API
      ├── صفحه‌های HTML سمت سرور (خبر، ورود، پنل کاربر، پنل ادمین)
      ├── API ‎/api/news
      └── D1 (SQLite)  ← جدول‌های خبر، کاربر، نشست، نظر، لایک، پیام و وضعیت ربات
              ▲
              │
      Cron Trigger هر ۶ ساعت
```

- **Worker** صفحه‌ها، API، احراز هویت، پنل ادمین و وب‌هوک تلگرام را مدیریت می‌کند.
- **Cron Trigger** هر ۶ ساعت خبرهای تازه را ذخیره و به کاربران مشترک تلگرام اطلاع می‌دهد.
- **D1** دیتابیس SQLite مدیریت‌شده‌ی Cloudflare است؛ جدول‌ها در اولین درخواست خودکار ساخته می‌شوند.

## اجرای پروژه روی سیستم شخصی

۱. وارد پوشه‌ی پروژه شوید و وابستگی‌ها را نصب کنید:

```bash
cd ~/Codes/mehran-news
npm install
```

۲. متغیرهای محلی را بسازید:

```bash
cp .dev.vars.example .dev.vars
```

سپس در `.dev.vars` نام کاربری و رمز ادمین اولیه را وارد کنید. این فایل در گیت نادیده گرفته می‌شود و نباید منتشر شود.

```ini
ADMIN_USERNAME="نام کاربری ادمین"
ADMIN_PASSWORD="رمز دلخواه ادمین"
```

ادمین فقط یک‌بار و در اولین درخواست ساخته می‌شود. بعد از آن می‌توانید ادمین‌های دیگر را از پنل مدیریت بسازید.

۳. سرور توسعه‌ی محلی را اجرا کنید:

```bash
npm run dev
```

۴. آدرس زیر را در مرورگر باز کنید:

```text
http://localhost:8787
```

جدول‌های D1 در اولین درخواست به‌صورت خودکار ساخته می‌شوند. اگر خواستید دستی هم بسازید:

```bash
npm run db:init:local
```

برای واکشی خبر در محیط محلی، با حساب ادمین وارد شوید و دکمه‌ی «به‌روزرسانی» را بزنید. این دکمه و مسیر `/refresh` فقط برای ادمین مجاز است:

```bash
curl -X POST http://localhost:8787/refresh \
  -H "Origin: http://localhost:8787" \
  -b cookies.txt
```

(فایل `cookies.txt` همان کوکی نشست ادمین است که با ورود در مرورگر یا `curl -c cookies.txt` ساخته می‌شود.)

برای تست دستی Cron:

```bash
curl http://localhost:8787/cdn-cgi/local/scheduled
```

دیتابیس محلی در پوشه‌ی `.wrangler/state` ذخیره می‌شود و با پاک‌کردن این پوشه، همه‌ی داده‌های محلی از نو ساخته می‌شوند.

> توجه: به‌صورت پیش‌فرض `wrangler dev` فقط روی همین سیستم در دسترس است. برای دسترسی از موبایل در شبکه‌ی خانه از `npx wrangler dev --ip 0.0.0.0` استفاده کنید. برای دسترسی از هر جای اینترنت، نسخه را روی Cloudflare منتشر کنید.

## استقرار روی Cloudflare

### ۱. ورود و ساخت دیتابیس

```bash
npx wrangler login
npx wrangler d1 create mehran-news
```

خروجی دستور دوم یک `database_id` می‌دهد. آن را در `wrangler.toml` قرار دهید:

```toml
[[d1_databases]]
binding = "DB"
database_name = "mehran-news"
database_id = "شناسه‌ی واقعی دیتابیس"
```

### ۲. تنظیم رمز ادمین به‌صورت Secret

رمز ادمین هرگز داخل کد یا `wrangler.toml` نوشته نمی‌شود. آن را یک‌بار به‌صورت Secret ذخیره کنید:

```bash
npx wrangler secret put ADMIN_USERNAME
npx wrangler secret put ADMIN_PASSWORD
```

هر دستور مقدار را به‌صورت پنهان می‌پرسد. ادمین در اولین درخواست به Worker ساخته می‌شود. اگر بعداً رمز را در Secret عوض کنید، رمز ادمینِ موجود به‌طور خودکار تغییر نمی‌کند؛ در این حالت حساب را از پنل مدیریت بازسازی کنید.

### ۳. انتشار

```bash
npm run deploy
```

### روش جایگزین با API Token

در داشبورد Cloudflare یک API Token با دسترسی‌های **Workers Scripts: Edit**، **D1: Edit** و **Account Settings: Read** بسازید و اجرا کنید:

```bash
export CLOUDFLARE_API_TOKEN="توکن شما"
export CLOUDFLARE_ACCOUNT_ID="شناسه‌ی حساب شما"

npx wrangler d1 create mehran-news
npx wrangler deploy
```

> Worker در اولین درخواست جدول‌ها را خودش می‌سازد؛ اجرای دستی `schema.sql` فقط برای بازسازی یا دیباگ لازم است.

## راه‌اندازی ربات تلگرام

ساخت ربات را خودتان انجام می‌دهید تا توکن در اختیار شما باشد:

۱. در تلگرام به **@BotFather** پیام دهید.
۲. دستور `/newbot` را بفرستید.
۳. یک نام نمایشی (مثلاً «مدیری‌نیوز») و سپس یک نام کاربری که به `bot` ختم می‌شود (مثلاً `ModiriNewsBot`) انتخاب کنید.
۴. BotFather یک **توکن** می‌دهد (قالبی شبیه `123456:ABC-DEF...`). این توکن مثل رمز است و نباید منتشر شود.
۵. در Cloudflare دو Secret ذخیره کنید:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_WEBHOOK_SECRET
```

مقدار `TELEGRAM_WEBHOOK_SECRET` را خودتان انتخاب کنید؛ رشته‌ای تصادفی و طولانی (مثلاً خروجی `openssl rand -hex 32`). تلگرام در هر درخواست وب‌هوک آن را در هدر `X-Telegram-Bot-Api-Secret-Token` می‌فرستد و Worker درخواست‌های بدون Secret درست را رد می‌کند.

۶. نام کاربری ربات را در `wrangler.toml` قرار دهید:

```toml
[vars]
TELEGRAM_BOT_USERNAME = "MehranNewsBot"
```

۷. دوباره منتشر کنید و در یک ترمینال وب‌هوک را ثبت کنید (توکن و Secret را از محیط بخوانید تا در تاریخچه‌ی شل ذخیره نشوند):

```bash
read -r -p "Bot token: " BOT_TOKEN
read -r -p "Webhook secret: " WEBHOOK_SECRET

curl -s "https://api.telegram.org/bot${BOT_TOKEN}/setWebhook" \
  --data-urlencode "url=https://mehran-news.farshidgholizadeh.workers.dev/telegram/webhook" \
  --data-urlencode "secret_token=${WEBHOOK_SECRET}" \
  --data-urlencode 'allowed_updates=["message","callback_query"]'
```

بعد از ثبت وب‌هوک، در ربات `/start` بزنید تا منو باز شود. دکمه‌های اصلی به‌صورت ثابت در پایین صفحه می‌مانند و هر گزینه پیام مستقل خودش را می‌فرستد: «پروفایل من» پروفایل را چاپ می‌کند، «آخرین اخبار» پنج پیام جدا (هر پیام یک خبر با دکمه‌ی «باز کردن خبر») می‌فرستد و «اعلان‌ها» صفحه‌ای با دکمه‌ی سوییچ می‌آورد که وضعیت روشن/خاموش را روی خود دکمه نشان می‌دهد. لمس آن دکمه فقط برچسب همان دکمه را عوض می‌کند و پیام تازه‌ای نوشته نمی‌شود. ادمین سایت با `/start` منوی مدیریت را می‌بیند. دکمه‌ی «بک» حذف شده است؛ اگر کیبورد قدیمی با دکمه‌های «بستن منو»، «بازگشت» یا «بک» را می‌بینید، یک بار `/start` بفرستید تا کیبورد تازه جایگزین شود.

### اتصال حساب کاربر به تلگرام

- کاربر از **پنل من → اعلان‌های تلگرام** دکمه‌ی «ساخت لینک اتصال» را می‌زند.
- لینک ساخته‌شده مستقیماً قابل کلیک است و تلگرام را باز می‌کند؛ نیازی به کپی کردن دستی لینک نیست.
- تا وقتی ادمین «اجازه‌ی اعلان» را فعال نکرده باشد، پیامی ارسال نمی‌شود. این کلید بعداً می‌تواند مبنای اشتراک پولی شود.
- کاربر با یک دکمه‌ی تاگل در پنل، دریافت اعلان را روشن یا خاموش می‌کند.

## دسترسی از موبایل

بعد از `npm run deploy` آدرسی شبیه این دارید:

```text
https://mehran-news.<نام-زیردامنه>.workers.dev
```

آدرس HTTPS است و از هر شبکه‌ای باز می‌شود. می‌توانید آن را به صفحه‌ی اصلی موبایل اضافه کنید. اگر `workers.dev` فعال نبود، در داشبورد Cloudflare وارد **Workers & Pages** شوید و برای حساب خود زیردامنه‌ی `workers.dev` انتخاب کنید.

## تنظیمات

| تنظیم | محل | توضیح |
|---|---|---|
| `MAX_AGE_DAYS` | `wrangler.toml` → `[vars]` | حداکثر سن خبر برای ورود به صفحه (پیش‌فرض ۴۵ روز) |
| `SITE_URL` | `wrangler.toml` → `[vars]` | آدرس عمومی سایت برای ساخت لینک‌های ربات |
| `TELEGRAM_BOT_USERNAME` | `wrangler.toml` → `[vars]` | نام کاربری ربات بدون `@` |
| `crons` | `wrangler.toml` → `[triggers]` | زمان‌بندی واکشی خودکار (پیش‌فرض هر ۶ ساعت) |
| `ADMIN_USERNAME` | Secret | نام کاربری ادمین اولیه |
| `ADMIN_PASSWORD` | Secret | رمز ادمین اولیه |
| `TELEGRAM_BOT_TOKEN` | Secret | توکن ربات تلگرام |
| `TELEGRAM_WEBHOOK_SECRET` | Secret | کلید اعتبارسنجی وب‌هوک تلگرام |
| فاصله‌ی ضداسپم | `src/index.js` | حداقل ۲ دقیقه بین دو به‌روزرسانی خودکار |
| طول عمر نشست | `src/auth.js` | ۳۰ روز |
| محدودیت ورود | `src/index.js` | ۸ تلاش ناموفق در ۱۰ دقیقه |
| منابع خبری | `src/feeds.js` | آدرس فیدهای بینگ‌نیوز و گوگل‌نیوز |

## API

| مسیر | روش | کاربرد |
|---|---|---|
| `/` | GET | صفحه‌ی اصلی خبرها |
| `/news/:id` | GET | صفحه‌ی خبر با نظرها و لایک |
| `/login` | GET/POST | ورود مشترک ادمین و کاربر |
| `/register` | GET/POST | ثبت‌نام کاربر (نیازمند تأیید ادمین) |
| `/panel` | GET | پنل کاربری، تنظیم اعلان تلگرام و پیام به مدیریت |
| `/panel/message` | POST | ارسال پیام کاربر به مدیریت |
| `/news/:id/like` | POST | لایک/برداشتن لایک؛ با هدر `Accept: application/json` پاسخ JSON برمی‌گرداند |
| `/admin` | GET | پنل مدیریت با تایل‌های کلیک‌پذیر (فقط ادمین) |
| `/admin/messages` | GET | صندوق پیام‌های کاربران (فقط ادمین) |
| `/api/news` | GET | لیست خبرها و آمار به‌صورت JSON |
| `/refresh` | POST | واکشی دستی خبرها (فقط ادمین) |
| `/telegram/webhook` | POST | وب‌هوک تلگرام (با Secret) |
| `/health` | GET | بررسی سلامت سرویس و وضعیت ربات |
| `/static/style.css` | GET | فایل استایل |

همه‌ی درخواست‌های `POST` (به‌جز وب‌هوک تلگرام) با بررسی `Origin`/`Sec-Fetch-Site` و کوکی `SameSite=Lax` در برابر CSRF محافظت می‌شوند.

## منابع و نحوه‌ی کار واکشی

- فیدهای RSS بینگ‌نیوز برای عبارت‌های «مهران مدیری» و «Mehran Modiri»
- فید گوگل‌نیوز برای عبارت «Mehran Modiri»
- لینک‌های ریدایرکتی بینگ به آدرس اصلی خبر تبدیل می‌شوند تا تکراری‌ها حذف شوند.
- عنوان، خلاصه و منبع هر خبر پاک‌سازی می‌شود و HTML داخل فیدها حذف می‌شود.
- خبرهای قدیمی‌تر از `MAX_AGE_DAYS` وارد پایگاه داده نمی‌شوند.

## نکات و محدودیت‌ها

- این پروژه از جست‌وجوی RSS استفاده می‌کند و متن کامل صفحات خبری را استخراج نمی‌کند.
- فید گوگل‌نیوز فارسی در بعضی شبکه‌ها خروجی خالی می‌دهد؛ پوشش اصلی فارسی از بینگ‌نیوز می‌آید.
- تصاویر بندانگشتی از خود فیدها می‌آیند و برای بعضی خبر‌ها وجود ندارند.
- فیلتر کلمات نامناسب مبتنی بر فهرست محلی است و صددرصد نیست؛ ادمین همچنان نظرها را بازبینی می‌کند.
- ارسال اعلان تلگرام فقط برای کاربرانی انجام می‌شود که ادمین اجازه داده و خودشان اعلان را روشن کرده‌اند.
- سقف‌های پلن رایگان Cloudflare برای یک سایت خبری شخصی کافی است.

## نسخه‌ی پایتون (قدیمی)

نسخه‌ی اولیه با پایتون و SQLite محلی در `legacy-python/` نگه داشته شده و در گیت نادیده گرفته می‌شود:

سپس `http://127.0.0.1:8000` را باز کنید.

## عیب‌یابی

**خطای `database_id` هنگام deploy:** شناسه‌ی واقعی D1 را در `wrangler.toml` قرار دهید.

**صفحه بالا می‌آید ولی خبری ندارد:** دکمه‌ی به‌روزرسانی را بزنید یا `curl -X POST https://<آدرس-worker>/refresh` را اجرا کنید.

**Cron اجرا نمی‌شود:** بعد از تغییر `[triggers]` دوباره `npm run deploy` کنید. Cron فقط در نسخه‌ی منتشرشده فعال است، نه در `wrangler dev`.

**ورود ادمین کار نمی‌کند:** مطمئن شوید `ADMIN_USERNAME` و `ADMIN_PASSWORD` به‌صورت Secret روی Worker تنظیم شده‌اند و Worker حداقل یک‌بار بعد از تنظیم Secret اجرا شده است.

**ربات تلگرام پیام نمی‌دهد:** `GET /health` را بررسی کنید (فیلد `bot` باید `true` باشد)، سپس صحت توکن و وب‌هوک را با `getWebhookInfo` ببینید. برای هر کاربر هم باید هم «اجازه‌ی اعلان» ادمین و هم سوییچ اعلان خود کاربر فعال باشد.

**دسترسی از موبایل برقرار نیست:** مطمئن شوید Worker منتشر شده و آدرس `workers.dev` فعال است. دسترسی به نسخه‌ی محلی از موبایل فقط با `--ip 0.0.0.0` و هم‌شبکه بودن گوشی و کامپیوتر ممکن است.
