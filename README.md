# مهران‌نیوز (mehran-news)

یک صفحه‌ی خبری مینیمال و فارسی که خبرها و مطالب مرتبط با **مهران مدیری** را از فیدهای خبری اینترنت جمع می‌کند، در دیتابیس **Cloudflare D1** ذخیره می‌کند و با **Cloudflare Workers** روی اینترنت سرو می‌کند. صفحه برای موبایل هم کاملاً واکنش‌گرا (Responsive) است.

## امکانات

- واکشی خودکار خبرها از بینگ‌نیوز (فارسی و انگلیسی) و گوگل‌نیوز
- فیلتر خبرها بر اساس نام «مهران مدیری» و حذف موارد نامرتبط
- حذف تکراری‌ها بر اساس لینک اصلی خبر
- ذخیره در SQLite روی Cloudflare D1
- نمایش خبرها گروه‌بندی‌شده بر اساس روز شمسی (امروز، دیروز، ۱۲ آبان و…)
- به‌روزرسانی خودکار هر ۶ ساعت با Cron Trigger
- دکمه‌ی به‌روزرسانی دستی
- ظاهر مینیمال راست‌چین با پشتیبانی خودکار از حالت روشن و تاریک
- نمایش تصویر بندانگشتی، منبع، زمان نسبی و خلاصه‌ی هر خبر
- فقط خبرهای ۴۵ روز اخیر (قابل تغییر) وارد صفحه می‌شوند

## معماری

```text
مرورگر / موبایل
      │
      ▼
Cloudflare Worker  ──── fetch ────►  بینگ‌نیوز / گوگل‌نیوز (RSS)
      │
      ├── صفحه‌ی HTML سمت سرور
      ├── API ‎/api/news
      └── D1 (SQLite)
              ▲
              │
      Cron Trigger هر ۶ ساعت
```

- **Worker** هم صفحه را رندر می‌کند و هم API و به‌روزرسانی دستی را پاسخ می‌دهد.
- **Cron Trigger** تابع `scheduled` را هر ۶ ساعت اجرا می‌کند و خبرهای تازه را ذخیره می‌کند.
- **D1** یک دیتابیس SQLite مدیریت‌شده در Cloudflare است؛ نیازی به سرور جداگانه یا فایل محلی روی سرور نیست.

## ساختار پروژه

```text
mehran-news/
├── src/
│   ├── index.js      # مسیرها، رندر صفحه، تریگر کرون
│   ├── feeds.js      # دریافت و پارس فیدهای RSS و حذف تکراری‌ها
│   ├── db.js         # لایه‌ی D1 و ساخت خودکار جدول‌ها
│   ├── jalali.js     # تبدیل تاریخ شمسی و نمایش زمان فارسی
│   └── style.js      # استایل صفحه
├── schema.sql        # ساختار دیتابیس (برای اجرای دستی)
├── wrangler.toml     # تنظیمات Worker، D1 و Cron
├── package.json
└── legacy-python/    # نسخه‌ی قبلی با پایتون (فقط مرجع محلی، در گیت نیست)
```

node --version

## اجرای پروژه روی سیستم شخصی

۱. وارد پوشه‌ی پروژه شوید:

```bash
cd ~/Codes/mehran-news
```

۲. وابستگی‌ها را نصب کنید (فقط wrangler):

```bash
npm install
```

۳. سرور توسعه‌ی محلی را اجرا کنید:

```bash
npm run dev
```

۴. آدرس زیر را در مرورگر باز کنید:

```text
http://localhost:8787
```

جدول‌های D1 در اولین درخواست به‌صورت خودکار ساخته می‌شوند. اگر خواستید دستی هم بسازید:

```bash
npm run db:init:local
```

برای تست واکشی خبر در محیط محلی، یکی از این دو کار را انجام دهید:

- روی دکمه‌ی «به‌روزرسانی» در صفحه کلیک کنید.
- یا در ترمینال اجرا کنید:

```bash
curl -X POST http://localhost:8787/refresh
```

برای تست دستی Cron در محیط محلی:

```bash
curl http://localhost:8787/cdn-cgi/local/scheduled
```

دیتابیس محلی در پوشه‌ی `.wrangler/state` ذخیره می‌شود و با پاک‌کردن این پوشه، همه‌ی داده‌های محلی از نو ساخته می‌شوند.

> توجه: به‌صورت پیش‌فرض `wrangler dev` فقط روی همین سیستم در دسترس است. اگر می‌خواهید در شبکه‌ی خانه از موبایل به نسخه‌ی محلی وصل شوید، از `npx wrangler dev --ip 0.0.0.0` استفاده کنید و آدرس IP کامپیوتر را در موبایل باز کنید. برای دسترسی از هر جای اینترنت، نسخه را روی Cloudflare منتشر کنید (بخش بعد).

## استقرار روی Cloudflare

### روش اول: ورود تعاملی با wrangler

```bash
npx wrangler login
```

سپس دیتابیس D1 را بسازید:

```bash
npx wrangler d1 create mehran-news
```

خروجی این دستور یک `database_id` می‌دهد. آن را در فایل `wrangler.toml` جایگزین مقدار فعلی کنید:

```toml
[[d1_databases]]
binding = "DB"
database_name = "mehran-news"
database_id = "شناسه‌ی واقعی دیتابیس"
```

سپس Worker را منتشر کنید:

```bash
npm run deploy
```

### روش دوم: با API Token (مناسب محیط بدون مرورگر)

در داشبورد Cloudflare یک API Token با دسترسی‌های زیر بسازید:

- **Workers Scripts: Edit**
- **D1: Edit**
- **Account Settings: Read** (برای خواندن Account ID)

سپس در ترمینال:

```bash
export CLOUDFLARE_API_TOKEN="توکن شما"
export CLOUDFLARE_ACCOUNT_ID="شناسه‌ی حساب شما"

npx wrangler d1 create mehran-news
npx wrangler deploy
```

اگر می‌خواهید ساختار جدول‌ها را از قبل روی دیتابیس ابری بسازید:

```bash
npx wrangler d1 execute mehran-news --remote --file=./schema.sql
```

> در حالت عادی نیازی به این دستور نیست؛ Worker در اولین درخواست جدول‌ها را خودش می‌سازد.

## دسترسی از موبایل

بعد از `npm run deploy`، آدرسی شبیه این دریافت می‌کنید:

```text
https://mehran-news.<نام-زیردامنه>.workers.dev
```

این آدرس HTTPS است و از هر شبکه‌ای (Wi-Fi یا داده‌ی موبایل) روی گوشی باز می‌شود. می‌توانید آن را به صفحه‌ی اصلی موبایل اضافه کنید تا مثل یک اپلیکیشن باز شود.

اگر آدرس `workers.dev` فعال نبود، در داشبورد Cloudflare وارد **Workers & Pages** شوید و برای حساب خود یک زیردامنه‌ی `workers.dev` انتخاب کنید. در صورت داشتن دامنه‌ی اختصاصی، می‌توانید در بخش **Settings → Domains & Routes** دامنه را به Worker وصل کنید.

## تنظیمات

| تنظیم | محل | توضیح |
|---|---|---|
| `MAX_AGE_DAYS` | `wrangler.toml` → `[vars]` | حداکثر سن خبر برای ورود به صفحه (پیش‌فرض ۴۵ روز) |
| `crons` | `wrangler.toml` → `[triggers]` | زمان‌بندی واکشی خودکار (پیش‌فرض هر ۶ ساعت) |
| فاصله‌ی ضداسپم | `src/index.js` | حداقل ۲ دقیقه بین دو به‌روزرسانی |
| منابع خبری | `src/feeds.js` | آدرس فیدهای بینگ‌نیوز و گوگل‌نیوز |

Cron پیش‌فرض:

```toml
[triggers]
crons = ["0 */6 * * *"]
```

این عبارت یعنی هر ۶ ساعت (ساعت‌های ۰، ۶، ۱۲ و ۱۸ به وقت UTC). برای واکشی روزانه یک‌بار، می‌توانید آن را به `"0 6 * * *"` تغییر دهید.

## API

| مسیر | روش | کاربرد |
|---|---|---|
| `/` | GET | صفحه‌ی اصلی خبرها |
| `/api/news` | GET | لیست خبرها و آمار به‌صورت JSON |
| `/refresh` | POST | واکشی دستی خبرها |
| `/health` | GET | بررسی سلامت سرویس |
| `/static/style.css` | GET | فایل استایل |

## منابع و نحوه‌ی کار واکشی

- فیدهای RSS بینگ‌نیوز برای عبارت‌های «مهران مدیری» و «Mehran Modiri»
- فید گوگل‌نیوز برای عبارت «Mehran Modiri»
- لینک‌های ریدایرکتی بینگ به آدرس اصلی خبر تبدیل می‌شوند تا تکراری‌ها حذف شوند.
- عنوان، خلاصه و منبع هر خبر پاک‌سازی می‌شود و متن HTML داخل فیدها حذف می‌شود.
- خبرهای قدیمی‌تر از `MAX_AGE_DAYS` وارد پایگاه داده نمی‌شوند.

## نکات و محدودیت‌ها

- این پروژه از جست‌وجوی RSS استفاده می‌کند و متن کامل صفحات خبری را استخراج نمی‌کند؛ برای خواندن کامل، لینک هر خبر باز می‌شود.
- فید گوگل‌نیوز فارسی در بعضی شبکه‌ها خروجی خالی می‌دهد؛ بنابراین پوشش اصلی فارسی از بینگ‌نیوز می‌آید.
- تصاویر بندانگشتی از خود فیدها (به‌طور عمده بینگ) می‌آیند و ممکن است برای بعضی خبر‌ها وجود نداشته باشند.
- دکمه‌ی به‌روزرسانی عمومی است، اما با محدودیت ۲ دقیقه‌ای از واکشی پشت‌سرهم جلوگیری می‌شود.
- سقف‌های پلن رایگان Cloudflare (تعداد درخواست‌های Worker و عملیات D1) برای یک صفحه‌ی خبری شخصی کافی است.

## نسخه‌ی پایتون (قدیمی)

نسخه‌ی اولیه‌ی پروژه با پایتون و SQLite محلی در پوشه‌ی `legacy-python/` نگه داشته شده است. این پوشه در گیت نادیده گرفته می‌شود و برای انتشار روی اینترنت استفاده نمی‌شود. اجرای آن (در صورت نیاز):

```bash
cd legacy-python
./run.sh
```

سپس آدرس `http://127.0.0.1:8000` را باز کنید.

## عیب‌یابی

**خطای مربوط به `database_id` هنگام deploy:** شناسه‌ی واقعی D1 را از خروجی `wrangler d1 create` در `wrangler.toml` قرار دهید.

**صفحه بالا می‌آید ولی خبری ندارد:** یک‌بار دکمه‌ی به‌روزرسانی را بزنید یا `curl -X POST https://<آدرس-worker>/refresh` را اجرا کنید. اگر فیدها در دسترس نباشند، پیام خطا نمایش داده می‌شود.

**Cron اجرا نمی‌شود:** بعد از هر تغییر در `[triggers]` دوباره `npm run deploy` کنید. Cron فقط در نسخه‌ی منتشرشده روی Cloudflare فعال است، نه در `wrangler dev`.

**دسترسی از موبایل برقرار نیست:** مطمئن شوید Worker منتشر شده و آدرس `workers.dev` در داشبورد فعال است. دسترسی به نسخه‌ی محلی از موبایل فقط با `--ip 0.0.0.0` و هم‌شبکه بودن گوشی و کامپیوتر ممکن است.
